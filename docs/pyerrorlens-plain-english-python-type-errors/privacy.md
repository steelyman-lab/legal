# Privacy Policy for PyErrorLens: Plain-English Python Type Errors

**Publisher:** Steelyman Lab
**Marketplace:** Visual Studio Code Marketplace
**Effective Date:** June 8, 2026

---

## 1. Overview

PyErrorLens: Plain-English Python Type Errors ("the Extension") is a Visual Studio Code extension published by Steelyman Lab. We take your privacy seriously. This policy explains what data we collect (spoiler: none), how the Extension works, and what your rights are.

This policy is written in plain English. If something is unclear, please reach out — we're happy to explain.

---

## 2. Data We Collect

**We collect no data. None at all.**

The Extension runs entirely on your local machine inside Visual Studio Code. It reads Python type error messages from your editor and translates them into plain English. This process happens locally and:

- No code is sent to any external server.
- No error messages are transmitted anywhere.
- No telemetry, analytics, or usage statistics are collected.
- No personal information is gathered.
- No files are read beyond what VS Code's extension API provides for its core function.

---

## 3. Data Storage and Retention

Because we collect no data, there is nothing for us to store or retain. The Extension does not write any data to disk beyond standard VS Code extension settings you configure yourself (such as toggle preferences). Those settings stay on your machine and are never accessed by us.

---

## 4. Third-Party Services

The Extension does not use any third-party services, APIs, or SDKs. There are no:

- Analytics platforms (e.g., no Google Analytics, Mixpanel, etc.)
- Crash reporting tools (e.g., no Sentry, Bugsnag, etc.)
- Cloud backends or databases
- AI/LLM APIs (all translation logic runs locally)

The only external interaction is the standard VS Code Marketplace update check, which is handled entirely by Microsoft under [their own privacy policy](https://privacy.microsoft.com/en-us/privacystatement).

---

## 5. Your Rights Under GDPR and CCPA

### GDPR (European Users)

Under the General Data Protection Regulation, you have rights including access, correction, deletion, and objection regarding your personal data. Because we collect no personal data, these rights have no practical application to the Extension. However, if you have any concerns, you are always welcome to contact us.

### CCPA (California Users)

Under the California Consumer Privacy Act, California residents have the right to know what personal information is collected, to request deletion, and to opt out of the sale of their data. Again, since we collect nothing, there is nothing to disclose, delete, or sell.

We do **not** sell personal data — ever.

---

## 6. Children's Privacy

The Extension does not target children, and because it collects no data whatsoever, there is no risk to minors' privacy.
